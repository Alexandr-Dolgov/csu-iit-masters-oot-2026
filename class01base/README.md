# class01base. Базовые понятия ООП. От структуры данных к объекту

## Тезисы:
* Процедурная программа
* Технические объекты
* Структурная программа, класс с полями как структура данных
* Создание объектов как структур, или "тупых" хранилищ данных
* Внутренности `System.out.println`, посмотреть документацию и провалиться в исходники
* Наследование класса
* Переопределение дефолтного/родительского поведения: toString
* Один объект под разными типами
* Полиморфизм на примере toString
* Области видимости в java
* Конструкторы класса
* Данные + поведение над ними = Класс в парадигме ООП
* Инварианты/ограничения
* Публичные методы = контракт/API/интерфейс класса
* Интерфейсы, реализация множества контрактов
* Объект может скрываться под ещё большим количеством типов
 и тип мы должны выбирать на том уровне абстракции, которого здесь будет хватаь
* Композиция vs Наследование
