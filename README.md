# Курс "Объектно-ориентированные технологии" для магистратуры Институт информационных технологий ЧелГУ, 2026


## Программа курса

8 занятий онлайн раз в неделю, по 2 академические пары. Язык — Java 21.

Занятие строится так: теория по слайдам → та же теория в коде → как это сделано в JDK и фреймворках →
совместная задача (студент берёт экран) или разбор ДЗ.
Паттерны сгруппированы по проблеме, которую решают; категория GoF указывается на слайде.

Код каждого занятия — отдельный модуль `classNN...`; OrderFlow занятия N начинается с конечного состояния занятия N−1.


## Домашние задания

* [ДЗ1](hw01/README.md) — по занятиям 1–2: тариф без `instanceof`, свой вариант отчёта и статуса, банковский счёт


## Темы занятий

### 1. Базовые понятия ООП. От структуры данных к объекту. Ответственность и абстракция

**Ключевые понятия:** класс, контракт, полиморфизм, интерфейс, композиция и наследование;
цена изменения, ответственность, абстракция, инкапсуляция, инвариант, 
значимый объект и сущность, примитивозависимость, связность и сцепление.

**Смотрим в JDK и фреймворках:** `Object`, `System.out.println`, `List.copyOf`.

**Совместная задача:** OrderFlow: от `legacy` к `domain`/`app`/`infra`, самовывоз одним классом.

### 2. Подстановка и паттерны поведения

**Ключевые понятия:** принцип подстановки (LSP), контракт `equals`/`hashCode`; 
паттерны, стратегия, шаблонный метод, состояние, команда, итератор; строитель.

**Смотрим в JDK и фреймворках:** `Comparator`, `AbstractList`, `List.of` → `UnsupportedOperationException`,
`Runnable`/`Callable`, `Iterable`, `HttpClient.newBuilder()`.

**Совместная задача:** виды промокодов → `Promo` как стратегия; нарушение LSP в `OrderRepository` «только для чтения».

### 3. Паттерны создания и обёртки

**Ключевые понятия:** фабричный метод, абстрактная фабрика, одиночка как антипаттерн; 
адаптер, декоратор, прокси, компоновщик.

**Смотрим в JDK и фреймворках:** `List.of`, `java.io`, `InputStreamReader`, `Arrays.asList`,
`Collections.unmodifiable*`, `java.lang.reflect.Proxy`, JUnit `DynamicContainer`.

**Совместная задача:** адаптер внешнего SMS-шлюза для `Notifier`; декораторы `Notifier`: повтор при сбое, логирование.

### 4. Spring собран из паттернов

**Ключевые понятия:** SOLID задним числом (S, O, L — где уже встречались), ISP, DIP;
инверсия управления, внедрение зависимостей; наблюдатель, цепочка обязанностей.

**Смотрим в JDK и фреймворках:** Spring `BeanFactory`, `@Bean`, `BeanPostProcessor`, AOP-прокси, `@Transactional`,
`ApplicationEvent`/`@EventListener`, Servlet `Filter`, Spring Security `FilterChain`.

**Совместная задача:** ручную сборку в `Main` заменить на Spring-контекст; 
«заказ оплачен» как событие вместо прямого вызова `Notifier`.

### 5. Разбор ДЗ

### 6. Тестируемость

**Ключевые понятия:** тестовые двойники (dummy, stub, spy, mock, fake), швы в унаследованном коде;
расширяемость фреймворка.

**Смотрим в JDK и фреймворках:** JUnit 5 Extension Model, `ParameterResolver`, Mockito (прокси, ByteBuddy).

**Совместная задача:** тесты `PlaceOrder` с двойниками; своё JUnit-расширение с фиксированными часами `Clock`.

### 7. Архитектура

**Ключевые понятия:** слои, гексагональная архитектура, порт и адаптер порта, правило зависимостей; итоги курса.

**Смотрим в JDK и фреймворках:** SLF4J (фасад + адаптеры), ArchUnit.

**Совместная задача:** JDBC-адаптер `OrderRepository` (H2); ArchUnit-тест «`domain` не зависит от `infra`».
